# Results — 2026-10-08 (first day on the GPU box)

## Pipeline validation on PHercParis4 segment 20231016151002 (known text; in ink_9um's training set)

| run | input | result |
|---|---|---|
| smoke test | pre-rendered 7.91 µm stack (33 layers, 9800×15960), ink_9um seed42 step-075000, `--direction both` | forward: faint but correctly placed text block; reverse: noise. ~5 min GPU (32,727 patches, RTX 3060). Scale mismatch (7.91 vs ~9.6 µm) explains the weak signal. |
| proper input | `vc_render_tifxyz --remote-url … -g 2 --scale 1 --num-slices 28` on the 2.4 µm volume (= 9.6 µm/px), crop x4000 y900 6500×2100 → 28×2100×6500 | **reverse direction: three legible lines of Greek**, matching the published reference line for line; forward: noise. 3,232 patches, ~1 min GPU. |

Lessons:
- Renders made without `--flip-normals` have the ink side in *reverse* layer order; run `--direction both` or render with `--flip-normals`.
- `--surface-interpolation smooth` for final renders (linear shows grid-cell stepping).
- Remote streaming works but is fragile: both the renderer (one 60 s chunk timeout) and the flat ink inference (one `ServerDisconnectedError`) abort on a single transient failure — see friction log #4/#5. Re-runs hit the persistent remote cache and finish in seconds.

## PHerc0800 (First Letters + Grand Prize eligible; NOT in training data)

Six public `auto_grown` segments (Oct 2025, ~1–2.7 cm across), pre-rendered 31-layer 8.64 µm stacks; ink_9um seed42-075k / seed43-075k / seed42-040k, both directions (36 outputs, 0 failures).
Result: **no letter-like structure in any output** — blobby, isotropic activity only; strongest "signal" (segments 20251028220955, 20251028220042) is blotches, not rows of strokes. Border "stamp" artifacts where patches straddle the mask edge (cosmetic).
Interpretation: these small test patches may not lie on text; the model window (17 of 31 layers, centered) may also miss the ink depth.

Next candidates (cheap → expensive):
1. Depth-window sweep on the same six stacks (`--layer-start/--layer-end`, 17-layer windows at offsets 0/4/7/10/14) + checkpoint averaging.
2. Re-render the PHerc0800 segments ourselves (`-g 0 --scale 1 --num-slices 28 --flip-normals --surface-interpolation smooth`) to rule out the published stacks' depth placement.
3. Spiral fitting on a ~1000-slice Z band of PHerc0800 (dataset exists at dl.ash2txt.org/datasets/spiral_datasets/PHerc0800/20250521135224/) → whole windings → render → infer. This is the First Letters guide's main route and the real work.
